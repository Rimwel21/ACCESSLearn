# SIGNHEAR Security Documentation

These documents describe the controls and remaining risks observed in the SIGNHEAR source code. They are engineering evidence for the capstone review, not a certification or a claim of legal compliance.

- `asset_inventory.md` — systems, data, owners, and protection needs
- `data_classification.md` — handling levels for actual SIGNHEAR data
- `security_architecture.md` — trust boundaries and implemented controls
- `threat_model.md` — credible threats, mitigations, and remaining work
- `backup_restore_plan.md` — recoverable data and restoration process
- `incident_response_plan.md` — practical incident-handling workflow
- `privacy_and_compliance.md` — privacy design considerations
- `dependency_inventory.md` — application components and review procedure

Review this folder when authentication, hosting, storage providers, data fields, or deployment architecture changes.
